**故障根因摘要（记录备忘）**

1. Harness D + panda `check_relay` 会 **阻断原厂** `ES_LKAS_ANGLE` (0x124)，OP 必须持续发合法替代帧。  
2. 若 inactive 角取自 `Steering_Torque` 而 safety 用 `Steering_2`，量纲/来源不一致 → TX 被丢 → EPS 无有效角流 → **LKAS/EyeSight 故障闩锁**（常需钥匙循环）。  
3. 现代限幅（可低至 ~0.15°/TX）与 carcontroller ~1°/step 不匹配 → TX 被拒 → 同上。  
4. **改 safety 后必须重编/刷 panda**。

## 11. 实车反馈与调参（2026-08-05）

### 现象

| 项目 | 结果 |
|------|------|
| OP 投入后手动优先 | **正常，不报错** |
| 松手后 OP 再接管 | **延迟偏大** |
| 转弯路 | **调控不足**，需手干预，否则易冲向路边 |

### 原因判断（代码侧）

为“手动优先不报错”加的 hand-control 过激：

1. **松手等待** `ANGLE_OVERRIDE_RELEASE_FRAMES = 25`（约 **0.5 s**）才重新 `LKAS_Request=1`。  
2. **进入手控阈值过低**（力矩 25 / `steeringPressed` 25）：弯道自回正力矩被当成“手在转”，中途掉横向。  
3. **软让权** 在 cmd–meas 差 **>3°** 且残留力矩 **>12** 时触发：弯道跟踪滞后时常见 → 再次掉横向。  
4. 次要：`steerActuatorDelay=0.1` 对 angle 弯道前瞻略紧。

**不是** 单纯“1°/step 限速不够”为主因（与 justin 同量级）；优先修误让权与释放延迟。

### 已改（`opendbc_repo`，仅 Python，**一般不必重刷 panda**）

| 参数 | 原值 | 新值 |
|------|------|------|
| `ANGLE_DRIVER_TORQUE_ON/OFF` | 25 / 12 | **50 / 22** |
| `ANGLE_ERR_YIELD_DEG` | 3° + tq>OFF | **8° + tq≥ON** |
| `ANGLE_OVERRIDE_RELEASE_FRAMES` | 25 (~0.5s) | **8 (~0.16s)** |
| `steeringPressed` 阈值 (LKAS_ANGLE) | 25 | **50** |
| `steerActuatorDelay` (OUTBACK_2023) | 0.1 | **0.2** |

文件：`carcontroller.py`、`carstate.py`、`interface.py`；说明见 `sunnypilot_subaru_c3/docs/OUTBACK_2023_ANGLE_PORT.md`。

### 部署与复测建议

1. 将 `sunnypilot_subaru_c3`（含 `opendbc_repo`）同步到 C3 `/data/openpilot`，重启 openpilot（**无需**因本次改 safety）。  
2. 路测检查：  
   - 松手后约 **0.2 s 内** 是否重新跟线；  
   - 中等弯、手放轻或不扶时是否仍持续压中；  
   - 主动拧方向是否仍优先手动且不报 EPS 故障。  
3. 若弯道仍偏晚/偏弱且已确认无误让权：再考虑略提低速角速率（须与 panda `subaru.h` 同步）或微调 `steerRatio` / live lateral delay。

## 12. 告警：高速跟车减速 / 弯道（2026-08-05）

### 现象

| 场景 | 表现 |
|------|------|
| 高速 OP 投入，前车减速 | 车先跟减速一小段 → **OP 告警**（多为「BRAKE! / Risk of Collision」） |
| 弯道 OP 跟不住 | 同时或随后 **告警**（多为「Take Control / Turn Exceeds Steering Limit」或转向临时不可用） |

### 原因

1. **高速 FCW 误报（原厂纵向）**  
   - 本车用 **EyeSight ACC 管纵向**（`openpilotLongitudinalControl=False`）。  
   - OP 仍会在 `hardBrakePredicted` 时打 **`EventName.fcw`**。  
   - 原逻辑仅在 `aEgo < -1.25` 时当作「原厂已在刹」而屏蔽；跟车轻减速时常达不到 → **假碰撞预警**。  

2. **弯道 steerSaturated**  
   - 角误差 >~2.5° 持续 `steerLimitTimer`(0.4s) → `lac.saturated`。  
   - 弯中欠转向 → **「Take Control / Turn Exceeds Steering Limit」**。  
   - 旧逻辑对 angle 车 sat 检查不尊重 carcontroller 限角。  
   - EPS `Steer_Warning` → **转向临时不可用**。

### 已改

| 改动 | 文件 |
|------|------|
| 原厂纵向时关闭 OP model/planner FCW | `selfdrive/selfdrived/selfdrived.py` |
| subaru 角饱和阈值 2.5°→6°；sat 尊重限角 | `latcontrol_angle.py` |
| LKAS_ANGLE `steerLimitTimer` 0.4→1.0s | `opendbc .../interface.py` |

与 §11 横向调参一并部署复测。真危险仍依赖 **原厂 FCW/AEB**（仪表/蜂鸣可能仍有，与 OP 屏蔽无关）。

## 14. 手/刹车同帧让权（2026-08-05）

现象：能开 OP，但 **手动转向或刹车 → EyeSight/LKAS 故障**。  
原因：简化 carcontroller 在 `latActive` 时一直 `LKAS_Request=1`，人手/刹车时与 EPS 对抗。

| 改动 | 值 |
|------|-----|
| 手控进/出力矩 | ON=**45** / OFF=**20** |
| 松手再接管 | **~0.16 s**（8 帧 @50Hz） |
| 刹车 | `brakePressed` 同帧让权，`Request=0`，角=实测 |
| `steeringPressed` (LKAS_ANGLE) | **45**（与手控一致） |
| `LKAS_Request` 打包 | 显式 0/1 |

文件：`carcontroller.py`、`carstate.py`、`subarucan.py`。panda 仍用已刷 **1°/TX** safety（无需再刷）。
